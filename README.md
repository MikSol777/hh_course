# Поиск вакансий на HeadHunter

Эта программа позволяет искать вакансии на HeadHunter.ru, сохранять их локально и фильтровать по различным критериям.

## Возможности

- Поиск вакансий на HeadHunter.ru
- Сохранение вакансий в локальный JSON файл
- Просмотр сохраненных вакансий
- Фильтрация вакансий по ключевому слову
- Получение топ N вакансий по зарплате

```
## Использование

Запустите программу:
python main.py
```

Программа предоставляет интерактивное меню со следующими опциями:

1. Поиск вакансий
   - Введите поисковый запрос
   - Просмотр результатов поиска
   - Фильтрация результатов по ключевому слову
   - Просмотр топ N вакансий по зарплате

2. Просмотр сохраненных вакансий
   - Просмотр всех ранее сохраненных вакансий

3. Выход из программы

## Структура проекта

- `main.py` - Основной файл программы с логикой взаимодействия с пользователем
- `src/api.py` - Интеграция с API HeadHunter
- `src/vacancy.py` - Реализация класса вакансии
- `src/storage.py` - Реализация JSON хранилища
- `src/parser.py` - Реализация парсера данных
- `vacancies.json` - Локальное хранилище вакансий (создается автоматически)

## Хранение данных

Вакансии автоматически сохраняются в `vacancies.json` при выполнении поиска. Это позволяет просматривать ранее найденные вакансии даже после закрытия программы.
